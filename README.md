# Small Office Network Lab (Cisco Packet Tracer)

## Overview
This project simulates a small office network built in Cisco Packet Tracer to practice foundational networking concepts.

## Objective
Configure a working local network where multiple devices can communicate successfully.

## Devices Used
- Cisco 1941 Router
- Cisco 2960 Switch
- 4 PCs
- 1 Server

## Network Configuration
Subnet: 192.168.1.0/24

Router:
192.168.1.1

PC0:
192.168.1.10

PC1:
192.168.1.11

PC2:
192.168.1.12

PC3:
192.168.1.13

Server:
192.168.1.20

## Skills Demonstrated
- IPv4 Addressing
- Static IP Configuration
- Router Interface Configuration
- Switching Fundamentals
- Default Gateway Configuration
- ICMP Connectivity Testing
- Basic Network Troubleshooting

## Validation
Connectivity was verified using successful ping tests between devices.
